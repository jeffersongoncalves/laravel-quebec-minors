# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 - 2026-11-18

First release of laravel-quebec-minors: consent of the person having parental authority or the tutor for minors under 14 (Quebec Law 25, ss. 4.1 and 14), age assurance stored as results, guardian links, no profiling for minors and an adult-only middleware. Part of the Quebec Law 25 suite for Laravel.
